# LASSARD — От кристалла до решения

Главная: index.html. 3D-студия: studio.html. Прогулка: walk.html.

Редакция 3: одна высокая стеклянная витрина справа с оптической заготовкой и готовым элементом, свободный обзор приборов, одна панель истории, декоративные экраны и 20 подвесных кристаллов по периметру. Анаморфная надпись из 218 трубок сохранена.

ТЗ на решение скачивается локально. 3D требует интернета для загрузки Three.js.
