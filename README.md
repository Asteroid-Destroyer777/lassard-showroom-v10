# LASSARD — От кристалла до решения

Шоурум промышленных решений. Версия 24.10.2026.

- У входа: три стойки — рост VGF, монокристалл GaAs и подложки.
- Над галереей: 218 красных трубок, которые складываются в LASSARD с отмеченной точки.
- На стенах: история производственных компетенций 2015–2025.
- Маршрут клиента: материал, оборудование, контроль результата, техническое задание на решение.
- Форма ТЗ скачивает файл локально. Для передачи менеджеру нужно отправить его отдельно.

Открыть: https://asteroid-destroyer777.github.io/lassard-showroom-v10/
